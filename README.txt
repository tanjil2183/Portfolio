ART OF LIVING PORTFOLIO — FINAL LOCAL PACKAGE

Files: index.html, course.html, quiz-bank.js, materials/*.pdf, CV and existing certificate PDF.

Quiz rules: 12 lessons; first 5 original questions per lesson are used for practice (60 total). The remaining 40 original questions are reserved for the final assessment. The final assessment draws 30 questions from that unused pool, passing threshold 18/30 (60%).

Certificate: after passing, the learner may enter name/email and print/save a locally generated certificate as PDF. This is NOT a secure online certificate registry; static GitHub Pages cannot enforce unique email issuance across devices or maintain a protected central record. That requires a configured backend/database.

Deployment: upload the package files to the root of the existing GitHub Pages repository, preserving the portfolio assets. No changes were made to the live website.

Note: video embedding depends on YouTube availability and whether the video owner permits embedding.
